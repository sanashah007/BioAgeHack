This table was built to test the argument that first-generation clocks leave too little residual to combine — and it does not support it: Hannum (1st gen) leaves 4.25 where GrimAgeV1 (2nd gen) leaves 3.93. Residual spread conflates signal with noise, and separating them needs an outcome this cohort does not have. The clock choice rests on published mortality evidence, not on this.

Scores are out-of-fold (5-fold cross-fitted), gaps are age-residualised, and every outcome model adjusts for chronological age and sex. Source data is NHANES 2005–2006 public-use files with the NCHS Public-Use Linked Mortality File through 2019-12-31.
