BioAge Console — biological age calculator + intervention protocol
==================================================================

TO OPEN:  double-click  BioAge_Console.html  (opens in any web browser).
No install, no internet required. Nothing you enter is uploaded — the whole
calculation runs on your own machine.

WHAT IT DOES:
  • Estimate biological age from blood + wearable markers (mortality-validated
    NHANES reference). Load a "held-out patient" chip to see it work instantly.
  • Methylation: drop one of the files in  demo_methylation/  onto the
    "Drop raw methylation data" pad to compute GrimAge + PhenoAge in-browser.
    IMPORTANT: first set the Age and Sex shown in the file's name
    (e.g. accelerated_age69 -> age 69), because the clocks use both.
  • Build a four-tier intervention protocol (diet/exercise -> supplements ->
    drugs -> peptides) to move each marker toward its elite range.

Not a medical device — educational, population-level associations only.
